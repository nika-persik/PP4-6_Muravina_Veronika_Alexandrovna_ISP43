# LibraryApp

## Описание проекта

LibraryApp - консольное приложение на языке C#, предназначенное для учёта книг в библиотеке.

Приложение позволяет добавлять книги, искать их по идентификатору, выдавать и возвращать. Также программа проверяет возможность выполнения операций и выводит сообщения при возникновении некорректных ситуаций.

## Используемые технологии

- C#;
- .NET;
- Microsoft Visual Studio.

## Структура проекта

- `Program.cs` - точка входа в программу, создание библиотеки и выполнение основных операций;
- `Book.cs` - класс, содержащий информацию о книге: идентификатор, название, автора и доступность;
- `Library.cs` - класс для управления книгами, включающий методы добавления, поиска, выдачи и возврата;
- `TEST_REPORT.md` - отчёт о тестировании приложения.

## Основные возможности

- добавление книг в библиотеку;
- поиск книги по идентификатору;
- выдача доступной книги;
- возврат ранее выданной книги;
- обработка попыток выдачи отсутствующей книги;
- предотвращение повторной выдачи и повторного возврата книги.

## Запуск приложения

1. Открыть файл решения проекта в Microsoft Visual Studio.
2. Убедиться, что проект `LibraryApp` выбран в качестве запускаемого.
3. Выполнить сборку проекта с помощью команды **Сборка -> Собрать решение**.
4. Запустить приложение клавишей `F5` или `Ctrl + F5`.
5. Ознакомиться с результатами выполнения операций в консоли.

## Тестирование

В ходе тестирования были выявлены и исправлены три дефекта:

1. Возникновение исключения при попытке выдать отсутствующую книгу.
2. Повторная выдача уже выданной книги.
3. Повторный возврат уже доступной книги.

Подробные сведения о найденных дефектах, способах их воспроизведения и результатах исправления приведены в файле `TEST_REPORT.md`.
