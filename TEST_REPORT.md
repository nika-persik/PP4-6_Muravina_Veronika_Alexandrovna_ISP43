# Отчёт о тестировании LibraryApp

## 1. Объект тестирования

Объектом тестирования является консольное приложение LibraryApp, разработанное на языке C# с использованием платформы .NET в среде Microsoft Visual Studio.

Приложение предназначено для учёта книг в библиотеке. Оно позволяет добавлять книги, искать их по идентификатору, выдавать читателям и возвращать. Для каждой книги хранятся идентификатор, название, автор и состояние доступности.

## 2. Методика тестирования

В ходе работы использовались следующие методы тестирования:

1. **Ручное тестирование.** Проверялась работа основных функций приложения путём запуска программы и анализа сообщений в консоли.
2. **Отладка.** С помощью точек останова и пошагового выполнения программы исследовалась работа методов `BorrowBook`, `ReturnBook` и `FindBook`. Проверялись ситуации выдачи отсутствующей книги, повторной выдачи и повторного возврата.
3. **Статический анализ кода.** Выполнялась сборка проекта в Microsoft Visual Studio, проверялись сообщения компилятора, корректность проверок условий и документированность методов.

После исправления обнаруженных дефектов соответствующие сценарии были выполнены повторно.

## 4. Результаты инспекции кода

В ходе инспекции исходного кода были выявлены следующие замечания:

1. **Отсутствие проверки результата поиска книги.** В методе `BorrowBook` не проверялось, была ли найдена книга. Это приводило к исключению `NullReferenceException`. Исправление: добавлена проверка на `null` с выводом сообщения об отсутствии книги.
2. **Отсутствие проверки доступности книги перед выдачей.** Метод `BorrowBook` позволял повторно выдавать уже выданную книгу. Исправление: добавлена проверка свойства `IsAvailable`.
3. **Отсутствие проверки состояния книги перед возвратом.** Метод `ReturnBook` позволял повторно возвращать уже доступную книгу. Исправление: добавлена проверка текущего состояния книги.
4. **Недостаточная документированность методов.** Для повышения понятности исходного кода добавлены XML-комментарии `summary` к публичным методам класса `Library`.

После внесения изменений была выполнена повторная сборка проекта. Дополнительно проверена обработка трёх сценариев, выявленных на этапе отладки.

## 5. Итоги

В ходе тестирования были обнаружены и исправлены три дефекта, связанные с выдачей отсутствующей книги, повторной выдачей и повторным возвратом.

После исправления программа корректно обрабатывает указанные ситуации, выводит соответствующие сообщения и не допускает некорректного изменения состояния книги.

Для проверки использовались ручное тестирование, отладка и статический анализ исходного кода. Проверены три сценария, соответствующие обнаруженным дефектам. Полное покрытие всех возможных сценариев не оценивалось, поскольку отдельные автоматизированные тесты не разрабатывались.

В дальнейшем рекомендуется проверить обработку некорректных идентификаторов, повторное добавление книг с одинаковыми идентификаторами и другие граничные ситуации.
